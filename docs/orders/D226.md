# D226 — رأس م١٤: إصلاح تمدد قائمة مقاسات الصور من مراجعة م١٣

## الدليل والنطاق
مراجعة م١٣ على b01def5، ملف مؤقت فيه ٢٤ قالب مقاس مصنوع: عند ١٢٨٠×٧٢٠ صار ارتفاع منطقة المقاس ٦٨٩، ومنطقة خطوات الصورة ٣٢، وخانة النسخ تنتهي عند y=769 والصفحة ٧٨٥. السبب قائمة المقاسات المرنة بلا حد داخل الجزء الثابت؛ P2، لا فقد بيانات.
## المسموح والخطوات
src/renderer/src/screens/photos/PhotoSizeOutput.tsx وحده: حد ارتفاع قائمة أزرار المقاسات وتمرير داخلي مسمى بلا حذف قالب أو تغيير اختياره أو حفظه أو دليل المقاس والإخراج. لا تغيير نموذج أو معالجة أو أي خطاف.
tools/scenarios/photoWorkspace.mjs: أبق فحوصه الـ٣٤، وأضف ٢٤ قالبًا عبر الجسر في ملف التشغيل المؤقت ثم أعد فتح الشاشة؛ ١٢٨٠×٧٢٠ و١٣٦٦×٧٦٨، مع فتح الدليل وبعد الصورة أيضًا. إثبات بقاء فتح الصورة والنسخ والإخراج ضمن الحيز، وتمرير القائمة حتى آخر قالب واختياره دون تمرير الصفحة أو فقد القوالب.
docs/sections/photos.md وUI وBACKLOG (ختم الملاحظة) وQUALITY وPLAN وLOG وهذا الأمر وأرشيف الدفتر عند حدّه.
## الفحص والختام
الفحص الجديد يجب أن يسقط على البناء القائم قبل الإصلاح؛ ثم typecheck وvitest كامل مرة والبناء، ثم photoWorkspace وphotoSteps وphotos وportrait. إسقاط الحد يجب أن يعيد إخفاق الفحص؛ حالة غياب الحد قبل الإصلاح هي الإسقاط نفسه ولا تعاد بلا سبب (ر172).
