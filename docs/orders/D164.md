## الخطوات
١. **الأصناف** في `styles.css` (`@layer components`، بجانب `.btn-act`، بتعليقٍ لكلٍّ):
   `.surface-panel` = `bg-grad-surface rounded-frame shadow-card border border-white/90` (لوحٌ كبير أو نافذة) ·
   `.input-field` = `rounded-field bg-surface-container-low border border-outline-variant` وتركيزه `bg-surface-container-lowest` وحدٌّ `#8CDCEB` وهالة `0 0 0 4px rgba(33,200,231,.10)` بلا `outline` ·
   `.btn-soft` = `rounded-btn bg-primary-fixed text-primary font-semibold` ومروره `bg-primary-fixed-dim` (زرٌّ ثانويّ بارز، كـ`.btn-s` في «ب٢»).
٢. **جدول الترجمة** في UI.md §٨ (يُطبَّق هنا وفي D165–D168 حرفًا):
   | قبل | بعد |
   |---|---|
   | لوحٌ كبير أو نافذة (`rounded-xl/2xl` أبيض وظلّ) | `.surface-panel` |
   | بطاقة (`rounded-xl/lg` أبيض و`shadow-[0_1px_8px…]` أو `shadow-sm/md`) | `rounded-card shadow-soft border border-outline-variant` |
   | زرّ الفعل (`bg-primary` أو `bg-primary-container` مع `text-on-primary`) | `.btn-act` بمقاسه وخطّه، ويُحذف `rounded-*` منه |
   | زرٌّ ثانويّ أو أيقونة (`rounded-lg`) | `rounded-btn` (والأبيض بحدٍّ: `border border-outline-variant shadow-low`) |
   | خانة (`input` `select` `textarea` بـ`rounded-lg` و`focus:ring-*`) | `.input-field` بمقاسها |
   | المختار (`ring-2 ring-secondary`، أو `bg-secondary`/`bg-primary-container` تحديدًا) | بطاقة: `border-2 border-cyan bg-grad-sel shadow-sel` · شريحة أو تبويب: `bg-primary-fixed text-primary` |
   | عددٌ أو شارة (`bg-secondary text-on-secondary rounded-full`) | `bg-grad-orange text-on-surface` (والتنبيه `bg-error` كما هو) |
   | شريحة تصفية `rounded-full` | `rounded-chip` |
   | قائمةٌ منبثقة أو تلميحٌ كبير (`shadow-xl/2xl`) | `shadow-card` و`rounded-card` |
   وما لا يقع في الجدول يُترك؛ والأحمر والبنّيّ والأسود فوق الصور كما هي.
٣. **التطبيق** على «المسموح» بالجدول. وما يُحسم مسبقًا (D158): شعار MADA TECH يبقى على بطاقةٍ داكنة (حروفه بيضاء) ويوحَّد لونها
   `bg-inverse-surface` في `AboutDialog` و`Onboarding` (كان `#0b1020` و`#16223F` كحليّ السكّة القديمة) · والرسائل العابرة `bg-inverse-surface` كما هي ·
   والستائر `bg-scrim/…` كما هي. إيداعٌ بعد الأصناف والجدول، ثم بعد كلّ نحو خمسة عشر ملفًّا (نقطة استئناف في الدفتر).
٤. `git grep -nE "bg-primary(-container)? text-on-primary"` في «المسموح» فارغ، و`rounded-lg` فيه لا يبقى إلا ما لا يقع في الجدول (يُعدّ في القيد).
