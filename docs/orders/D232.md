# D232 — م١٥: وصف البرنامج ومطابقة متجر مايكروسوفت
> ⚙️ م · يعتمد على D231 ✅

## المطلوب والحدود والفحص
اكتب docs/policies/STORE-DRAFT.md: وصف عربي قابل للمراجعة يطابق الوظائف الحالية والخصوصية والتجربة والحزم؛ لا تسويق ذكاء سحابي أو توقيع حكومي أو تراخيص صور غير ثابتة. اقسم نص العرض عن قائمة متطلبات النشر الداخلية.
تحقق بالويب من سياسات Microsoft Store الرسمية الحالية: الخصوصية داخل التطبيق ورابط عام، شروط الترخيص/الشراء والخطط التجريبية وطريقة التوزيع، مسار MSIX والتوقيع مقابل EXE/MSI بما يطابق هدف ر179، الأذونات والتصنيف والمحتوى وحقوقه ومواد الإدراج وملاحظات الاختبار. لا اختيار قناة بيع/سعر/حساب/ناشر قانوني نيابة عن المالك، ولا تضمن قبول المتجر.
اكتب docs/policies/OWNER-APPROVAL.md يجمع مسودات D229–D232 وروابطها وخيارات الاقتراح والحقول التي يحتاجها المالك، مع فصل اعتماد النص عن الحقوق والنشر. لا ربط داخل التطبيق أو نشر URL أو بناء/رفع حزمة متجر أو شراء. راجع الاتساق يدويًا وروابط الملفات؛ حارس الوثائق/النظافة. المسموح الملفات الجديدة وM15-evidence وPLAN وLOG وBACKLOG والأمر. ختم وإيداع ودفع ونقل ثم D233 🛑.
