مراجَعةٌ لكلٍّ سببه — بثلاث مكتباتٍ للتطوير وحده لا تدخل المثبّت.

## الخطوات
١. `npm install -D eslint typescript-eslint eslint-plugin-react-hooks` بإصداراتٍ مستقرّة عمرها أسبوعان فأكثر، تعمل مع TypeScript ٥٫٧ وReact ١٨ وNode ٢٤ —
   وكلٌّ بإصداره في الدفتر. ولا تدخل `BUNDLED` (`npm run notices` لا يغيّر `notices.json`).
٢. **`eslint.config.mjs`** (flat): `src/**/*.{ts,tsx}` بمحلّل typescript-eslint بلا مشروع أنواع (سريع)، وقاعدتان وحدهما: `react-hooks/rules-of-hooks: error`
   و`react-hooks/exhaustive-deps: warn` — لا قواعد أسلوب. و`"lint": "eslint src"`.
٣. `npm run lint`: إن وُجد خرقٌ لـ`rules-of-hooks`: **توقّف** واكتبه بمواضعه — إصلاحه يمسّ سلوك الواجهة فهو أمرٌ آخر.
٤. **`tests/lint.test.ts`** بواجهة ESLint البرمجية: صفر أخطاء · وتحذيرات `exhaustive-deps` ومواضع `eslint-disable` لا تزيد على سقفين في الاختبار بعددهما اليوم
   (ينقصان ولا يزيدان، كسقوف `structure`) · مهلته ٦٠ ث، ويُكتب زمنه في الدفتر.
٥. **مراجعة الثلاثة والأربعين** واحدًا واحدًا: (أ) مقصودٌ (نداءٌ مرّةً عند التركيب، أو دالّةٌ ثابتة الهويّة…) — فوقه تعليق سببٍ من سطرٍ إن غاب ·
   (ب) خطأٌ حقيقيّ (قيمةٌ قديمة تُقرأ) — بندٌ جديد في PLAN بمواضعه، ولا يُصلح هنا. وفي الدفتر عدد كلّ صنف.
٦. **الوثائق:** QUALITY §٢ (ESLint في طبقة الهيكل، وأمر `npm run lint`) و§١٠ (السقفان) و§١١ (ESLint أُغلق) · system.md §٦ يُرفع G05 و§٧ `lint` ·
