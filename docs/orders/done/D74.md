# D74 — A12: ثغرتا تبعيّات exceljs العابرة تُسدّان بلا حزمةٍ جديدة، وpdf-lib لا تحديث له

> الوسم: ⚙️ · يعتمد على: D73 · بعده: D75 · البند: A12 (ج-٩ في تدقيق ت١، P3)
> كُتب نصّه في D71 (١٨ ت١ ٢٠٢٦، 🧭) — تراجعه الجلسة التالية قبل تنفيذه.

## الهدف
`npm audit --omit=dev` يقول اليوم «3 vulnerabilities (2 moderate, 1 high)»، وكلّها عبر exceljs: **brace-expansion** (عالية: `archiver@5.3.2` ← `archiver-utils` ←
`glob@7.2.3` ← `minimatch@3.1.5` ← `1.1.18`، و`readdir-glob@1.1.3` ← `minimatch@5.1.9` ← `2.1.4`؛ «fix available via `npm audit fix`») و**uuid** (متوسّطة:
`exceljs@4.4.0` ← `uuid@8.3.2`؛ و`--force` يُنزل exceljs إلى 3.4.0 — مرفوض). وexceljs يستعمل `v4` وحده في موضعٍ واحد (`cf-rule-ext-xform.js`) فالثغرة
(v3/v5/v6 بمخزنٍ معطى) لا تمسّ استعماله — والسدّ لنظافة التدقيق قبل النشر. بعد الأمر: «found 0 vulnerabilities»، بلا اسم حزمةٍ جديد في ملفّ القفل
ولا تغيّرٍ في `dependencies` (القاعدة ٨: السبع) · وpdf-lib: `npm view pdf-lib version` ← 1.17.1 = المثبَّت، فلا تحديث له، ويُغلق ذلك الشطر بسببه.

على أربعة أسطر — فيُعادان.
