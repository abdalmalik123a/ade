# D98 — A09 (ب): حذف مجلّدات `before-restore-*` يدويًّا بتأكيد، وتوثيق حدّ FAT32، وختام أعمال الموجة ٣ قبل الإصدار

> الوسم: ⚙️ · الحجم: م · يعتمد على: D97 · البند: A09 (ب)

## الهدف
إغلاق A09 (ب) — آخر بندٍ قابلٍ للتنفيذ في الموجة ٣ قبل الإصدار:
١. تمكين المكتب من رؤية وحذف مجلّدات البيانات المنقولة جانبًا عند الاسترجاع (`before-restore-*`) **يدويًّا بتأكيد** (DECISIONS «مرفوضٌ بأسبابه»: لا تُحذف تلقائيًّا أبدًا) من «الإعدادات ← البيانات والنسخ الاحتياطية».
٢. توثيق سلوك النسخة التلقائية واليدوية مع فلاشات FAT32 (الحدّ ٤ غيغا للملفّ الواحد؛ والتلقائية تكتب كلّ ملفٍّ في المخزن وحده ونسخة القاعدة وحدها، ويبقى الفحص على فلاشةٍ حقيقية في G08 👤).

## الخطوات
١. **الخدمة (`src/main/services/restoreSwap.ts`):**
   - أضف `listBeforeRestore(dir: string): { name: string; at: string; bytes: number }[]` تقرأ مجلّدات `^before-restore-(\d{4}-\d{2}-\d{2})-(\d{2})-(\d{2})-(\d{2})$` داخل `dir` (أحدثها أوّلًا، بحجم محتوياتها بالبايت).
   - أضف `deleteBeforeRestore(dir: string, name: string): boolean` تتحقّق أنّ `name` يطابق `^before-restore-[\w-]+$` وأنّه ليس المجلّد المذكور في `restore-incomplete.json` إن وُجد، ثم تحذف `join(dir, name)` وتعيد `true`.
٢. **الجسر (`apiOffice.ts` و`preload/office.ts` و`ipc/backup.ts`):**
   - أضف نوع `BeforeRestoreAside = { name: string; at: string; bytes: number }` وقناتَي `listAsides(): Promise<BeforeRestoreAside[]>` و`deleteAside(name: string): Promise<boolean>` تحت `backup` في `apiOffice.ts` و`preload/office.ts`.
   - في `ipc/backup.ts` سجّلهما بـ`handleChecked` (`'backup:listAsides'` بلا معاملات، و`'backup:deleteAside'` بحارس `{ name: text(120) }` مع قيد `logAudit` عند الحذف) — مع اختصار أسطرٍ قليلة في `ipc/backup.ts` ليبقى <= ٤٠٠ سطر.
٣. **الواجهة (`BackupAsides.tsx` جديد و`BackupPanel.tsx`):**
   - أنشئ `src/renderer/src/components/BackupAsides.tsx` يعرض مجلّدات `before-restore-*` إن وُجدت (`data-before-restore-list=""`) مع تاريخ كلّ مجلّدٍ وحجمه وزرّ «احذف» (`data-act="delete-before-restore"`) يسأل بـ`ask` («حذف البيانات المنقولة جانبًا؟» بتأكيدٍ أحمر `danger` وافتراضيّ «ابقِ عليها») قبل نداء `window.diwan.backup.deleteAside(name)`.
   - ركّب `<BackupAsides />` في آخر `BackupPanel.tsx` (ويُعاد تحميل قائمتها بعد الاسترجاع) مع إبقاء `BackupPanel.tsx` <= ٤٠٠ سطر.
٤. **الاختبار والسيناريو والوثائق:**
   - أضف اختبارات `listBeforeRestore` و`deleteBeforeRestore` (يرفض اسمًا بـ`..` أو غير `before-restore-*` ويرفض المجلّد المذكور في `restore-incomplete.json`) في `tests/restoreSwap.test.ts`.
   - حدّث `docs/sections/system.md` و`docs/BACKLOG.md` (إغلاق A09، وبقاء فحص الفلاشة الحقيقية تحت G08 👤، وبقاء A17 وA18 وحدهما في جدول الموجة ٣ لما بعد الإصدار).
