## الخطوات
١. توثيق ر192 والحجز؛ تعديل التوكنات والأصناف الموجودة، لا مكوّنات أو آلية موازية؛ إبقاء لون primary النصّي داكنًا،
   وتخصيص لون العسلي لأفعال الإخراج حتى لا يصير نص الأيقونات والروابط عسليًا ضعيف التباين.
٢. تطبيق التركيز السيان والضغط الداخلي وتعطيل الظل عند disabled، وحركة ١٦٠ ملّي ثانية واحترام تقليل الحركة؛
   تحديد النماذج بحد سيان وعلامة واضحة، واستجابة خفيفة لإضافة سطر السلّة؛ لا حركة مستمرة ولا أصوات.
٣. توثيق المظهر الجديد وفحصه؛ إيداعان بعد الخطوات الكبيرة مع قيد يذكر الاختبارات؛ ثم الفحص الختامي مرة واحدة.
