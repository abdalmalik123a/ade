# D103 — تهيئة بيئة Rust وهيكل native/diwan-psd وتمرير إضافة فارغة في الطريق كلّه حتى الحزمة

> الوسم: ⚙️ · الحجم: ص · يعتمد على: D102 وموافقة المالك وتثبيته rustup · بعده: D104 · البند: A20 (ر164)

## الهدف
إنشاء مجلّد `native/diwan-psd` وتهيئته بـ`napi-rs` مع دالّة اختبار `psdEngineVersion()` تعيد رقم الإصدار،
وبناؤها وربطها في العامل `src/main/worker/index.ts`، والتحقّق من فكّ ملف `.node` في حزمة الاختبار التجريبية (`npm run pack`).

## اقرأ فقط
`docs/ARCHITECTURE.md` §«أوّل محرّك Rust (A20)» · `package.json` (`scripts` و`asarUnpack`) ·
`electron.vite.config.ts` · `src/main/worker/index.ts` · `tests/structure.test.ts`.

## تحقّق قبل البدء
موافقة المالك الصريحة على الأدوات وتثبيته `rustup` · `rustc --version` و`cargo --version` ينجحان في سطر الأوامر ·
D102 ✅ ومُراجَع. وإلا: **توقّف، واكتب السبب في الدفتر.**

## المسموح
`native/diwan-psd/` (جديد) · `package.json` (`scripts` فقط لبناء Rust) · `src/main/worker/nativePsd.ts` (جديد) ·
`src/main/worker/index.ts` · `tests/structure.test.ts` · `tests/workerJobs.test.ts` · `.gitignore` · PLAN والدفتر.

## الخطوات
١. **هيكل Rust:** إنشاء مجلّد `native/diwan-psd` يحوي `Cargo.toml` بالاعتمادات المعتمدة (`napi` و`napi-derive`)، و`src/lib.rs` بدالّة `psd_engine_version() -> String`.
٢. **سكربت البناء:** إضافة سكربت `build:native` في `package.json` وضمه إلى `npm run build`، وإضافة نواتج بناء Rust إلى `.gitignore`.
٣. **عقد العامل:** إنشاء `src/main/worker/nativePsd.ts` يحمّل الإضافة مع التقاط الخطأ وتسجيله في سجلّ الأخطاء والرجوع التلقائي إن تعذّر التحميل.
٤. **الحراسة:** قاعدة في `tests/structure.test.ts` تضمن تحميل الإضافة الأصلية من `nativePsd.ts` وحده داخل العامل، واختبار النداء في `tests/workerJobs.test.ts`.
٥. **الحزمة:** التحقّق بـ`npm run pack` من وجود ملف `.node` داخل مجلّد `app.asar.unpacked`.
