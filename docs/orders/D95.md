> الوسم: ⚙️ · الحجم: ص · يعتمد على: D94 · البنود: A13 (٤–٥) وA15

## الهدف
١. تثبيت إصدار Node الأدنى في `package.json` (`"engines": { "node": ">=22" }`) وملفّ `.nvmrc` جديد (`22`).
٢. إضافة فقرة «إن لم يُفتح البرنامج» في `docs/INSTALL.md` تشرح أين يُحفظ سجلّ الأخطاء (`%APPDATA%\Diwan\logs\diwan-errors.log`) وكيف يُرسل إلى المطوّر.
٣. إضافة `resources/installer.nsh` جديد يعرّف `LangString x64WinRequired 1025` بالعربية ليظهر على ويندوز ٣٢ بت بدل الرسالة الإنكليزية «64-bit Windows is required» (A15).

١. **`package.json` و`.nvmrc`:** أضف `"engines": { "node": ">=22" }` في `package.json`، وأنشئ `.nvmrc` وفيه `22\n` (LF).
٢. **`docs/INSTALL.md`:** أضف قسم `## إن لم يُفتح البرنامج` قبل `## أين البيانات` يذكر: إن لم تظهر النافذة أو ظهرت رسالة تعذّر التشغيل، فملفّ سجلّ الأخطاء في `%APPDATA%\Diwan\logs\diwan-errors.log` — أرسله مع صورة الرسالة إلى المطوّر بواتساب، وبياناتك في `%APPDATA%\Diwan\data` محفوظةٌ لا تُمسّ.
