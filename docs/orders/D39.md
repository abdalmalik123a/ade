# D39 — اختبار مكوّنات الواجهة وحدها ببيئة DOM (G03)

> الوسم: ⚙️ · يعتمد على: D38 · بعده: D40 · البند: G03 (المصدر ب85) · وافق المالك على jsdom وحده (قيد الدفتر ٢١:٣١، س٢)

## الهدف
مكوّنات الواجهة تُختبر وحدها في vitest ببيئة jsdom — ملفّاتها وحدها، والباقي `node` كما هو — بثلاثة اختباراتٍ أولى لسلوكٍ يعرفه الموظف، بلا سيناريو ولا مكتبةٍ غير jsdom.

## اقرأ فقط
`vitest.config.ts` · `tsconfig.web.json` و`tsconfig.test.json` و`scripts.typecheck` · `src/renderer/src/kit/useToast.ts` (L28) · `src/renderer/src/components/LetterSheet.tsx`
(`data-repeat-head`) و`src/shared/docHtml.ts` (`pageCss`) · `src/renderer/src/components/PrintChooser.tsx` و`src/renderer/src/lib/printChoice.ts` (`registerPrintChooser`
و`choosePrinter`) · `src/preload/*.d.ts` (نوع `window.diwan`) · `docs/QUALITY.md` §٢ §٥ §١١ · `docs/UI.md` §١٥ · `docs/sections/system.md` §٦ §٧.

## تحقّق قبل البدء
D38 ✅ · لا jsdom ولا happy-dom في `package.json` · `environment: 'node'` و`include: ['tests/**/*.test.ts']` · `tsconfig.test.json` يمتدّ من `tsconfig.node.json`
(بلا DOM ولا JSX) · React ١٨٫٣ (فيه `act`). وإن خالف الواقع: توقّف واكتب السبب.

## الخطوات
١. `npm install -D jsdom` بإصدارٍ مستقرّ عمره أسبوعان فأكثر (ويُكتب في الدفتر) · كلّ ملفٍّ في `tests/ui/` يبدأ بـ`// @vitest-environment jsdom`.
٢. **`tests/ui/mount.tsx`:** يركّب المكوّن بـ`createRoot` و`act` من React ١٨، ويفكّه بعد كلّ اختبار، و`window.diwan` مزيَّفٌ بما يحتاجه المكوّن وحده.
٣. **`useToast.test.tsx` (L28):** رسالتان متتاليتان — مؤقّت الأولى لا يمحو الثانية (`vi.useFakeTimers`) · `sticky` تبقى · `dismiss` يلغي المؤقّت · وفكّ المكوّن يلغيه.
٤. **`letterSheet.test.tsx`:** `repeatLetterhead` مع ترويسة ← الترويسة في `thead` داخل `[data-repeat-head]`، وبدونه لا جدول · `pageNumbers` ← في `<style>` «صفحة » و`counter(pages)`.
٥. **`printChooser.test.tsx`:** `choosePrinter('designs', { allowSystem: true })` ودورٌ بلا طابعة ← المنتقي بطابعات الجسر المزيّف والافتراضية مختارة · Enter ← `{ system: false }`
   بطابعتها · Esc ← `null` · «بإعدادات ويندوز…» ← `system: true` · ودورٌ بطابعةٍ مسمّاة ← لا منتقي (`direct`).
٦. **كسرٌ مؤقّت** يُعاد في الحال: حذف `clear()` من `say` في `useToast` ← اختبار L28 يسقط · ثم `git diff -- src` فارغ.
٧. **الوثائق:** QUALITY §٢ (طبقة «المكوّنات» بأمرها وبيئتها) و§٥ (الثلاثة في صفوف أقسامها) و§١١ (G03 أُغلق) · UI.md §١٥ يُرفع G03 · system.md §٦ يُرفع G03 و§٧ ·
