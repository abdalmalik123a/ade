# D214 — S33: تنقية عناوين المستمسك الكردية مع بقاء النص الأصلي

> ⚙️ م · يعتمد على D213 ✅ · بعده D215 🛑 · ر181 وتحديد المالك ٢٩ ت١ (ر183)

## الهدف واقرأ فقط
النص المعروض والمنسوخ ينقّى من العنوان الكردي المعروف بجانب عنوانه العربي، مع إمكان عرض الأصل ونسخه؛ الأصل المخزون وثقة OCR لا يتغيران.
اقرأ services/ocr وipc/citizens (attachments:ocr) وuseCitizenActions وOcrPanel وapiCitizens وscan، وسيناريو mrzRead؛ لا ملء حقول عربية جديد.

## تحقّق قبل البدء
المسار العام يرجع نصًا وثقة ويخزنهما دون تحليل حقول؛ الملء المنظم الموجود من MRZ. جُرّبت صور المالك محليًا بمحرك البرنامج؛ عناوين كردية وأخطاء OCR موجودة. المالك اختار صراحة تنقية المعروض والمنسوخ وإبقاء الأصل.

## الخطوات
١. دالة نقية للعرض: إزالة عبارات العناوين الكردية المعروفة فقط، مربوطة بعنوانها العربي وفي جانب العنوان قبل النقطتين. تشمل الاسم والأب والجد واللقب والأم والجنس والدم والولادة والإصدار والنفاذ والجهة والأرقام؛ المسافات والفواصل والعلامات الاتجاهية المحتملة تُراعى. لا حذف حروف كردية على العموم ولا نص قيم أو سطر مجهول؛ الملتبس يبقى ولا يخمّن.
٢. اختبارات ببيانات مختلقة: عناوين ثنائية اللغة وصيغ قراءة واقعية، قيم عربية وتواريخ وأرقام سليمة، اسم يشبه عنوانًا داخل القيمة، نص عربي عادي، عنوان غير معروف ومقلوب وMRZ. إسقاط حارس جانب العنوان يفسد اختبار المحافظة على القيمة، ثم يُعاد.
٣. OcrPanel: المعروض والمنسوخ هو المنقّى افتراضيًا، وزر واضح للأصل عند وجود فرق؛ النسخ يطابق العرض واسم الزر يوضح الأصل حين اختياره. لا تنظيف قراءة MRZ ولا النص المخزون ولا الثقة ولا الملء القائم؛ يشرح أن النص ما زال يحتاج مراجعة.
٤. سيناريو تطبيق حقيقي يرسم صورة بطاقة مصنوعة ويقرأها بمحرك OCR المحلي، يثبت فرقًا في عنوان معروف دون افتراض ثقة عالية؛ يعرض المنقّى والأصل ويختبر الحافظة وما خُزن، ولا MRZ يتغير. حدّث الوثائق بحدود التنقية. إيداع.

## الممنوع
تعديل صور المالك أو إدخالها أو قيمها في إيداع، أو محرك أو قاموس جديد، أو تغيير البحث وطيّ الحروف، أو ملء حقول عربية تلقائيًا أو تغيير ناتج OCR المخزون.

npm run typecheck · الاختبارات الموجهة ثم npx vitest run كاملًا مرة · npx electron-vite build ثم idOcrText وmrzRead عبر tools/drive.mjs. لا فحص شامل. مراجعة المنطق بقيم تحتوي الكلمات نفسها، وبقاء الأصل؛ الصور الحقيقية للمعاينة المحلية فقط ولا نجاح مضمونًا لكل تشوه OCR.
