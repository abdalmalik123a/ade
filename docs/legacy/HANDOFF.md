## ١ — قواعد المالك (لا تُخالَف)

1. **بدايةٌ بإذنه:** «ابدأ» تُبدأ بها الأعمال الكبيرة (التصاميم). وهذه الحزمة أذِن بها يوم ٨ ت١ وقال «أكمل» بعد كلّ مجموعة. **بعد كلّ مجموعة: نقطة مراجعةٍ بالعربية البسيطة (ما صار، وكيف فُحص، وما لم يُختبر، وما التالي) ثم انتظر «أكمل».**
2. **إيداعٌ محلّيّ لكلّ بند** على `packs`: رسالته بالعربية، أوّلها رمز البند (`د١ — …`)، وفيها الخلل وما أُصلح وكيف فُحص. **لا دمج في `master`/`production` ولا إصدار ولا وسم** إلا بأمره. الرفع إلى GitHub بإذنه (أذِن برفع `packs` يوم ٨ ت١): `git fetch origin` ثم دفعٌ سريع التقدّم فقط، **بلا `--force`**، وتحقّق بـ`git ls-remote origin`.
3. **«ما أُنجز يُكتب تمّ الإنجاز ولا يُعاد»:** بعد كلّ بند حدّث صفّه في `PROGRESS.md` (✅ + الإيداع + الفحص) وفي فقرة المجموعة «تمّ الإنجاز ولا تُعاد» وتحتها «طريقتها» بسطرٍ لكلّ بند؛ وأضف صفوف الاختبارات الجديدة في `TESTING.md`، وبنود الأجهزة التي لا تُختبر آليًّا في `docs/HARDWARE-CHECKLIST.md`. (وإن كانت لك ذاكرةٌ دائمة فحدّثها.)
4. **ميزانية الاختبار:** بعد كلّ بند: `npm run typecheck` + `npx vitest run` (نحو ٢٠ ثانية) + **سيناريوهات ما مسّه التغيير وحدها** (`npm run build` أوّلًا ثم `node tools/drive.mjs tools/scenarios/<اسم>.mjs`، واطبع الفاشل فقط `| grep ✗`). **لا فحص شاملًا** إلا بقول المالك «اكتمل».
5. **البرنامج ليس برنامجًا ماليًّا:** لا مبالغ ولا حسابات (المال «صامت»). الطلبات مقبولة بلا مال.
6. **لا بيانات شخصية في أيّ إيداع:** لا أسماء مدراء أو معلّمين أو زبائن أو مدارس حقيقية؛ أمثلة الكود والاختبارات مختلَقة («سالم حسن»، «مدرسة النور»). والمستودع خاصّ مع ذلك. ولا يُلمس مجلّد المالك ولا مفتاحه الخاصّ أبدًا.
7. **لا تعديل في شاشة التصاميم** (`DesignsScreen.tsx` وما حولها) — ستُطوَّر بالكامل. بنودها في `DESIGNS.md` لا هنا.
8. **قرارات المالك** الجامعة في جدول `DEVELOPMENT.md` (راجع الصفوف المؤرَّخة ٨ ت١). أهمّها لهذه الحزمة: الجنس **يبقى يسأل** · التفقيط لا يُحذف · لا مفتاح بديل مجّاني · الحفظ التلقائي للأسئلة والشبّاك **بعد أوّل بيع** · `.doc`/`.xls` لا نستعين بـWord/Excel لتحويلها · **احترام الحفظ والاستئناف القائمين** (المسودّة، والمعلّقة، وسجلّ الطباعة): ما تحرسه مسودّةٌ أو معلّقة لا يُسأل عنه ولا تُبنى آليةٌ موازية.

## ٢ — كيف تعمل (أوامر وعادات)

على جهازٍ جديد (ويندوز، Node 24 وnpm 11 يوم التسليم): `git clone -b packs https://github.com/abdalmalik123a/ade.git` ثم `npm install` (يُركّب better-sqlite3 لـElectron عبر `postinstall`) ثم `npm run build`.
المستودع **خاصّ**؛ والمالك يدخله بحسابه. وأدوات المالك ومفتاحه الخاصّ **ليست فيه** ولا تُطلب.

```bash
npm run typecheck            # ثلاثة مشاريع tsconfig
npx vitest run               # الوحدة. تأمّل سطر Errors في الخلاصة: «Errors 1 error» وعدٌ مرفوضٌ بلا التقاط (يُحسب فشلًا)
npm run build                # لا بدّ منه قبل أيّ سيناريو (يقود التطبيق المبني في out/)
node tools/drive.mjs tools/scenarios/deleteGuards.mjs
```

- **السيناريو** يقود التطبيق الحقيقي عبر CDP (`tools/drive.mjs`): `page.eval(...)` يلفّ الكود في دالّةٍ async (استعمل `return`)، و`page.goto('<data-path>')` ينقر السكّة (فيمرّ بحارس المغادرة)، و`page.key('Escape')` ضغطةٌ حقيقية،
  و`clickText` تبحث بـ«يحتوي» (استعمل `clickExact` أو سمة `data-act`). حقول React لا تُملأ بـ`el.value=`: مُعيِّن الخاصّية الأصلي ثم `dispatchEvent(new Event('input',{bubbles:true}))` (والقائمة: `'change'`).
  المنفذ ٩٢٢٣ واحد: لا سيناريوهان معًا. `export async function prepare()` يعيد متغيّرات بيئة الأبواب، و`afterRestart` يُعيد الفتح بعد قتلٍ، و**`betweenRestarts({profile})` بينهما والبرنامج مغلق**.
- **أبواب الاختبار** (`DIWAN_TEST_*`، لا توجد إلا تحت المِقْود): `SAVE_DIR` `OPEN_FILE` `OPEN_FILES` `OPEN_DIR` `SCAN_FILE` `PRINT_LOG` `FAKE_CAMERA` `CLOSE_ANSWER=stay,leave` (أجوبةٌ بالترتيب لسؤال إغلاق البرنامج) وغيرها في `TESTING.md`.
- **أسئلة الواجهة** (`kit/ask.ts`): في السيناريو `[data-confirm]` و`[data-choice="yes|no|stay|discard|save"]`؛ و**Esc أو النقر خارجها = الجواب الاحتياطي**.
- **كتابة الملفّات:** بعضها CRLF (`App.tsx`, `preload/index.ts`, `TemplateDesigner.tsx`, `DEVELOPMENT.md`, `PROGRESS.md`, `FOUNDATION.md`, `TESTING.md`, `HARDWARE-CHECKLIST.md`) وسائرها LF — اقرأ نهايات الأسطر قبل التعديل ولا تخلطها.
  **والأقواس العكسية `\` وفواصل الأسطر داخل نصوصٍ تمرّ بقشرة bash (heredoc) تُشوَّه:** اكتب الملفّات والسكربتات بأداة الكتابة لا بـ`cat <<EOF`.
- **الخطّافات (hooks):** كلّها قبل أيّ `return` مبكّر في المكوّن. وأيُّ شاشةٍ جديدة فيها عملٌ بلا مسودّة تُسجَّل بـ`useLeaveGuard` (`src/renderer/src/kit/`)؛ وما له مسودّةٌ أو معلّقة لا تُسجَّل.
- **الرسائل بالعربية للمكتب:** لا إنكليزية خامًا. أخطاء الواجهة: `errorText(e, 'احتياط')` من `lib/errors.ts`؛ وأخطاء SQLite تُترجَم عند حدّ القنوات (`ipc/errors.ts`).
- **الكتب الصادرة لا تتغيّر أبدًا:** كلّ كتابٍ يحفظ ورقته كما طُبعت. ولا ترقيم يُحرَق ولا بصمة تُمسّ ولا سلسلة تنكسر (`documents:verify`).

**د٢ — المسودّات: زرّ حذف، وليست في رقم السكّة.** *(قراره: «تُحذف ولا تُعدّ في رقم السكّة كالجرس».)*

## ٧ — ما يفعله المالك بنفسه (ذكّره بلطف)

1. **مفتاح «تمديد» لجهازه قبل ١٦ تشرين الأول ٢٠٢٦** (تجربة جهازه تنتهي يوم ١٥) من «أداة مفاتيح ديوان» بكلمته.
