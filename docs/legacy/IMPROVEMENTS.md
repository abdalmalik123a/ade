مختلفة إحداها مرتفعةٌ تخفي الرقبة، وجدارٌ بيج قريبٌ من لون الجلد) في `reports/صور-الاختبار/` خارج git — **لا تُودَع**؛ والاختبارات
المودَعة بصورٍ مولَّدة.
