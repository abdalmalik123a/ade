# فحص الإصدار على الأجهزة الحقيقية — للمالك

ما لا يُختبر آليًّا: الطابعات والماسح، والحسابات والسياسات، والكهرباء والقرص. يُجرى على **المثبّت نفسه**
(`release/diwan-X.Y.Z-setup.exe`) قبل أن يُباع الإصدار، وتُكتب نتيجة كلّ بندٍ بجانبه.

## التثبيت

| ✓ | البند | المتوقَّع |
|---|---|---|
| ☐ | تثبيتٌ نظيف على جهازٍ لم يُثبَّت عليه ديوان | SmartScreen يُتجاوز بـ«تشغيل على أي حال»، ثم معالج البداية، و«تجريبية — بقي 14 يومًا» |
| ☐ | التثبيت والبرنامج مفتوح | المثبّت يطلب إغلاقه، ثم يكمل ويُفتح البرنامج ببياناته كما هي |
| ☐ | حساب ويندوز بلا صلاحيات مدير | يُثبَّت ويعمل كلّه |
| ☐ | حسابٌ باسمٍ عربي (مسار المستخدم عربي) | يُثبَّت، وتُحفظ النسخ وPDF، ويعمل الماسح والقارئ الضوئي |
| ☐ | Windows Defender مفعّل، وسياسة PowerShell مقيّدة (`Restricted`) | لا يُحجر المثبّت؛ والماسح (WIA عبر PowerShell) يعمل — وإلا كُتب سببه |
| ☐ | إلغاء التثبيت | يُزال البرنامج، ويبقى `%APPDATA%\Diwan\data` |

## الطابعات (أدوار الطباعة — المرحلة ٢)

| ✓ | البند | المتوقَّع |
|---|---|---|
| ☐ | ليزر للكتب وملوّنة للصور في «الإعدادات ← الطابعات» | الكتاب يخرج على الليزر بلا سؤال، والصورة على الملوّنة |
| ☐ | طابعتان لدور الكتب (عادي وملوّن) | «على أيّ طابعة؟» مرّةً واحدة، وتخرج الأوراق كلّها عليها |
| ☐ | «اسأل» مُشعل | قائمة الطابعات في نافذة البرنامج، و«بإعدادات ويندوز…» يفتح نافذة ويندوز مرّةً للمهمّة |
| ☐ | الشبّاك: معاملةٌ بخمس أوراق، ثم يُنزع ورق الطابعة في منتصفها | «توقّفت الطباعة: طُبعت ن من ٥» — و«أكمل الطباعة» يكمل من التالية بعد إعادة الورق |
| ☐ | انقطاع الكهرباء في منتصف دفعة تصاميم | الإقلاع التالي يسأل «توقّفت عند …» ويستأنف |
| ☐ | معايرة الطابعة | ورقة المعايرة تخرج، وقياسان بالمسطرة يُصلحان الإزاحة على استمارةٍ مطبوعة سلفًا |
| ☐ | ورقة المستمسكات المجمّعة | الوطنية ٨٥٫٦×٥٤ والسكن ١٠٥×٧٤ ملم بالمسطرة على الورقة |
| ☐ | إعادة طبع كتابٍ قديم من الأرشيف | يخرج بخطّه وتقسيمه يوم صدر |

## الماسح

| ✓ | البند | المتوقَّع |
|---|---|---|
| ☐ | «فحص الماسح الضوئي» والمسح إلى ملفّ مواطن | يُرى الماسح، ويُحفظ المستمسك |
| ☐ | عدّة بطاقاتٍ بمسحةٍ واحدة، ثم ظهورها | تُقصّ كلّ بطاقة وتُطابق ظهورها |

## الجهاز والقرص والكهرباء

| ✓ | البند | المتوقَّع |
|---|---|---|
| ☐ | جهازٌ ضعيف بقرص HDD وذاكرة ٤ غيغا | الإقلاع والإصدار والبحث بلا تجمّد؛ ونسخةٌ احتياطية لأرشيفٍ كبير تكتمل |
| ☐ | نزع القابس بعد «اطبع» مباشرة | الكتاب مقيّدٌ برقمه بعد الإقلاع، والأرشيف «سليم» في سجلّ التدقيق |
| ☐ | امتلاء القرص ثم الإصدار | يُقال السبب ولا يُحرق رقم صادر، ولا تفسد القاعدة |
| ☐ | استرجاع نسخةٍ احتياطية (عاديّة ومشفّرة، ومن مجلّد النسخة التلقائية بنسخةٍ قديمة) | تعود البيانات، وما كان يُنقل جانبًا |

## التفعيل والتحديث

| ✓ | البند | المتوقَّع |
|---|---|---|
| ☐ | «أداة مفاتيح ديوان» من الفلاشة على جهازٍ آخر: تُفتح بكلمتك، وتقول إن المفتاح يطابق البرنامج | «المفتاح يطابق مفتاح البرنامج» |
| ☐ | مفتاحٌ مدى الحياة من الأداة لرمز الجهاز | «مفعَّل مدى الحياة»، ويختفي شريط المدّة |
| ☐ | مفتاح اشتراكٍ شهري على جهازٍ آخر | «اشتراك شهري حتى …»، والشريط قبل يومه بأسبوع |
| ☐ | الساعة تُقدَّم ١٥ يومًا على جهازٍ غير مفعّل | يتوقّف الإصدار والطباعة، ويبقى العرض والنسخ |
| ☐ | تحديثٌ من الأداة («ملفّ تحديث») على جهازٍ يعمل بالإصدار السابق | يُفحص، و«ما الجديد»، ويُثبَّت، وتُنسخ البيانات في `before-update/` قبل ترحيلها |
