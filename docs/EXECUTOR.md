# تجهيز المنفّذ — محادثة Claude الثانية (ر176 ر177)

> **لمن:** المنفّذ (النموذج الثاني من Claude) والمالك قبل أوّل `/next`. كتبه المخطِّط بأمر المالك ٢٤ ت١ ٢٠٢٦: «جميع الاسكلز والادوات التي يحتاجها ابلغه ان يضيفها».
> **والمنفّذ يقرؤه مرّةً في أوّل محادثته الأولى**، فإن نقصه شيءٌ أضافه (أو طلبه من المالك في سطرٍ واحد إن لم يملكه)، ثم يمضي في السلسلة.

## ١. المكان
- **Claude Code** (التطبيق المكتبي، تبويب Code) على مجلّد المستودع نفسه، والفرع `packs` — والدفع إليه fast-forward وحده (CLAUDE.md §الإنهاء).
- **النموذج:** ما يختاره المالك للمنفّذ؛ والأوامر **ك** و🧭 و🔍 أحسن بأقوى نموذجٍ متاح.
- **الخطّافات:** `.claude/settings.json` فيه الحارس قبل الأدوات وبعدها و**حارس الاستمرار** (`Stop`) — إن سأل Claude Code عن الوثوق بخطّافات المشروع يُوافَق مرّةً.

## ٢. الأدوات على الجهاز — يتحقّق منها بأمرٍ واحد في أوّل محادثة
| الأداة | يحتاجها | التحقّق |
|---|---|---|
| Node وnpm و`node_modules` | كلّ أمر | `node -v` و`npm run typecheck` |
| Git بصلاحية الدفع | الختام | `git ls-remote origin packs` |
| Python 3 مع Pillow وnumpy | D155 (`make-brand.py`)، وD160 (مرجع `prepare-suits.py`) | `python -c "import PIL, numpy"` |
| Rust (`cargo`) وVisual Studio Build Tools 2022 | إن مسّ أمرٌ محرّك PSD (`tools/buildNative.mjs`) | `cargo -V` |
| Electron للتشغيل والسيناريوهات | كلّ ما يراه المكتب | `npx electron-vite build` ثم `node tools/drive.mjs tools/scenarios/theme.mjs` |
| Windows Sandbox | م٧ وحدها (بيد المالك) | — |

## ٣. المهارات والإضافات — يضيفها المنفّذ قبل أوّل أمرٍ يحتاجها
| الإضافة | من أين | لماذا |
|---|---|---|
| **frontend-design** | إضافات Anthropic الرسمية | لازمةٌ لأوامر «ب٢»: D156 وD157 وجرد D158 وأوامره |
| **Design** (`design-critique` و`accessibility-review` و`ux-copy` و`design-system`) | إضافات Anthropic الرسمية | جرد D158، ونقد الشاشات، والتباين، والكلمات |
| **Context7** (MCP) | دليل MCP | وثائق Electron وpdf-lib وonnxruntime-node وProseMirror حين يُشكّ في واجهةٍ برمجية |
| **البحث في الويب** (WebSearch وWebFetch) | أدوات Claude Code | تراخيص نماذج D159 من مستودعاتها الرسمية (ر177 §٢) |
| **المتصفّح المدمج** | تطبيق Claude | قراءة صفحة ترخيصٍ أو وثيقةٍ إن لم يكفِ البحث |
والأمر `/next` في المستودع (`.claude/commands/next.md`) فلا يُضاف. وما لا يلزم المنفّذ: لوحات التصميم (Artifacts) — من شأن المخطِّط والمالك.

## ٤. الأذونات — حتى لا يتوقّف عند كلّ أمر
يختار المالك وضعًا لا يسأل عن الأوامر المعتادة، أو يضيف المنفّذ (بمهارة `fewer-permission-prompts` أو `update-config`) سماحًا لهذه وحدها:
`npm run typecheck` · `npx vitest run …` · `npx electron-vite build` · `node tools/drive.mjs …` · `node tools/…` · `python tools/…` ·
`git status|diff|log|show|add|mv|commit|push origin packs|ls-remote` · `npm run pack`.
**ولا يُسمح مسبقًا** بما يسأل عنه الحارس عمدًا: الإصدار والوسم والدمج وتثبيت اعتمادية وتحديث اللقطات و`tools/sweep.mjs` (ر177 §٤).

## ٥. البدء
أوّل رسالةٍ في محادثة المنفّذ: **`/next`** — وهو يقرأ الدفتر وPLAN والمرحلة الجارية من `docs/CHAIN.md`، ثم يمضي أمرًا بعد أمرٍ حتى 🛑 م٧.
- **إن توقّف بقيد «توقّف»:** آخر رسالته سطران بما يحتاجه؛ يجيب المالك ثم `/next` (أو «أكمل»).
- **إن نفد الرصيد:** محادثةٌ جديدة بـ`/next` تكمل من نقطة 🔄 في الدفتر.
- **المخطِّط والمنفّذ لا يودِعان معًا:** المخطِّط يقرأ ويراجع متى طلب المالك («راجع م١» مثلًا)، ويودِع ملفّاته وحدها بـ`git commit -- <ملفّاته>`.

## ٦. ما لا يُسأل عنه وما يُسأل (ر177)
- **يُحسم ويُكتب في القيد:** شرط بدءٍ قديمٌ آليًّا · شاشةٌ لم تُرسم في «ب٢» تأخذ توكناته · كلمةٌ ليست في القاموس تُضاف بسطر · صور القياس من `reports/صور-الاختبار/` ·
  نموذجٌ يوفّي معايير ر177 §٢ · `nativePsdCompare` القسم ٥ (بيئة).
- **يُسأل المالك وحده (🛑):** الإصدار والوسم والدمج والفحص الشامل · الشراء والتوقيع · اختبارات الميدان · واجهة الفوتوشوب S17 · اعتماديةٌ npm أو crate جديدة · ما يغيّر قرارًا مكتوبًا.
