# حزمة الجامعات والتعليم العالي (`higher-education`)

حزمة نماذج ومعاملات جامعية معتمدة للجامعات والكليات والمعاهد العراقية.

## المحتويات
- **UNI-01**: تأييد استمرار بالدراسة الجامعية (كتاب رسمي صادر)
- **UNI-02**: طلب تأييد استمرار بالدراسة الجامعية (استدعاء طالب)
- **UNI-03**: طلب تأجيل دراسي لسنة أو كورس
- **UNI-04**: طلب وثيقة تخرج بالدرجات معنونة
- **UNI-05**: طلب نقل أو استضافة جامعية
- **٤ كليشات جامعية معتمدة**
