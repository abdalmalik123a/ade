# حزمة الأحوال المدنية والبطاقة الوطنية (`civil-status`)

حزمة نماذج ومعاملات واستدعاءات مخصصة لدوائر البطاقة الوطنية والأحوال المدنية في العراق.

## المحتويات
- **CIV-01**: طلب إصدار بطاقة وطنية بدل ضائع أو تالف
- **CIV-02**: طلب تصحيح خطأ مادي في السجل المدني
- **CIV-03**: طلب إصدار البطاقة الوطنية أول مرة
- **CIV-04**: طلب فصل قيد عائلي وتأسيس صحيفة أسرية
- **٤ كليشات رسمية للأحوال المدنية**

## المصادر والتحقق

- قانون الأحوال المدنية رقم 65 لسنة 1972
- تعليمات مديرية الأحوال المدنية والجوازات والإقامة / وزارة الداخلية العراقية
