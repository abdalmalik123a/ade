# حزمة الاستدعاءات والطلبات العامة (`general-requests`)

حزمة نماذج المعاريض والطلبات الرسمية والتظلمات الإدارية القياسية في العراق.

## المحتويات
- **GEN-01**: معروض رسمي عام (طلب / استدعاء مواطن لأي جهة)
- **GEN-02**: تظلم إداري من قرار
- **GEN-03**: طلب مقابلة مسؤول حكومي (وزير / محافظ / مدير عام)
- **٣ كليشات رسمية عامة**
