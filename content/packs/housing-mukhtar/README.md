# حزمة السكن وبطاقة السكن والمخاتير (`housing-mukhtar`)

حزمة نماذج تأييدات السكن المعتمدة من المخاتير واستدعاءات مكاتب معلومات السكن في العراق.

## المحتويات
- **HOU-01**: تأييد سكن من مختار المحلة (الصيغة القياسية المعتمدة)
- **HOU-02**: طلب إصدار أو تجديد بطاقة سكن (مكتب معلومات السكن)
- **HOU-03**: طلب تأييد تغيير محل السكن والانتقال
- **٣ كليشات رسمية لتأييدات السكن**
