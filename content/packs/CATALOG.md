# كتالوج حزم الجهات الرسمية لمكاتب الطباعة والاستنساخ في العراق

أُعدّ هذا الكتالوج يوم ٤ تشرين الأول ٢٠٢٦ استناداً إلى دراسة متطلبات مكاتب الاستنساخ والطباعة في العراق، ومسح الخدمات الإدارية الحكومية المتكررة عبر بوابة أور الإلكترونية (`ur.gov.iq`)، والقوانين والأنظمة والتعليمات المنشورة في الوقائع العراقية، والأعراف الإدارية المتداولة في مكاتب المحافظات.

---

## ١ — القواعد والضوابط الصارمة

1. **لا اسم جهةٍ بعينها أبدًا**: لا يجوز ذكر «مدرسة الرشيد» أو «محكمة بداءة الكرخ» أو «مديرية تربية الرصافة الأولى». الحزمة تُبنى لنوع الجهة (القسم)، والجهة المخاطَبة حقلٌ يملؤه الموظف (`المرسل_إليه` أو `اسم_المدرسة` أو `اسم_الكلية`).
2. **لكلّ معاملةٍ مصدرٌ وتاريخ تحقّق**: ما لا مصدر له لا يدخل البرنامج؛ وحالته إما «مصدر رسمي» برابطه ومادته، أو «عُرف متداول — يراجعه المالك» موصوفاً بدقة.
3. **لا بيانات ناس**: لا أسماء حقيقية ولا أرقام هويات ولا مستمسكات.
4. **لا توقيع ولا ختم ولا شعار دولة ولا رمز تحقّق**: الورقة المطبوعة توقّع وتختم بيد الجهة الحية.
5. **ليس برنامجًا ماليًّا**: لا وصولات ولا كمبيالات ولا بيع ولا عقود ولا وكالات (محذوفة بقرار المالك ٢٩ أيلول ٢٠٢٦).
6. **الصياغة للجنسين**: كل نموذج يُصاغ بدقة للمذكر والمؤنث `{الطالب|الطالبة}` مع إدراج حقل «الجنس».
7. **سلامة مفاتيح الحقول**: عدم استخدام مفاتيح تطابق قاموس الزبون خطأً (`الجهة`، `المديرية`، `الدائرة`، `القسم`) منعاً لملئها تلقائياً من «مكان عمل الزبون»، واستخدام `المرسل_إليه` ونحوه.
8. **المعرّفات ثابتة للأبد**: توليد المعرفات عبر UUID v5 بمساحة اسم ثابتة لضمان عدم تكرار النماذج أو تضاربها عند إعادة البناء.

## ٣ — الأقسام اللاحقة المقترحة (تنتظر مراجعة المالك بعد اعتماد التربية)

### أ. الأحوال المدنية والبطاقة الوطنية (`civil-status`)
- **طلب إصدار / تجديد البطاقة الوطنية**: استدعاء تظلم أو فقدان أو تصحيح بيان ولادة/زواج أمام مديرية شؤون البطاقة الوطنية.
- **طلب تصحيح لقب أو خطأ مادي**: بموجب قانون البطاقة الوطنية رقم 3 لسنة 2016.
- **استدعاء فقدان هوية أحوال / بطاقة وطنية**: تمهيداً للإعلان ونشر الفقدان وتدوين أقوال المحكمة.
- **المصادر**: موقع مديرية شؤون البطاقة الوطنية (`https://nid-moi.gov.iq`) وبوابة أور.

### ب. السكن وبطاقة السكن والمخاتير (`housing-mukhtar`)
- **تأييد سكن من المختار**: صيغة عريضة مصادقة المختار على سكن المواطن في المحلة والزقاق والدار.
- **طلب إصدار بطاقة سكن جديدة / نقل سكن**: مكتب معلومات السكن المركزي ومكاتب المحافظات.
- **المصادر**: تعليمات مكاتب معلومات السكن / وزارة الداخلية، وقانون المختارين رقم 13 لسنة 2011.

### ج. البلديات وعقارات الدولة والإسكان (`municipalities`)
- **طلب براءة ذمة بلدية / دفع رسوم مهنة**: لدوائر البلدية.
- **طلب شراء / تمليك دار سكنية**: وفق القرار 154 أو القوانين النافذة لتمليك المتجاوزين (قرار مجلس الوزراء 320 لسنة 2022).
- **اعتراض على تقدير بدل الإيجار أو الرسوم**: أمام لجان التقدير البلدية.
- **المصادر**: قانون إدارة البلديات رقم 165 لسنة 1964 وقوانين أمانة بغداد وبوابة أور.

### د. الجامعات والتعليم العالي (`higher-education`)
- **طلب تأجيل دراسي لسنة أو كورس**: بموجب تعليمات التعليم العالي رقم 134 لسنة 2000.
- **طلب تأييد تخرج / وثيقة بالدرجات**: موجه إلى عمادة الكلية / المعهد.
- **طلب استضافة / نقل بين الجامعات**: تعليمات الانتقال والاستضافة السنوية لوزارة التعليم العالي (`https://mohesr.gov.iq`).

### هـ. التأييدات والطلبات العامة والاستدعاءات (`general-requests`)
- **استدعاء رسمي عام (معروض / طلب)**: الصيغة الإدارية العراقية القياسية لأي وزارة أو جهة غير محددة.
- **طلب مقابلة السيد المسؤول (الوزير / المحافظ / المدير العام)**.
- **تظلم إداري من قرار**: بموجب قانون انضباط موظفي الدولة والقطاع العام رقم 14 لسنة 1991 المعدل أو قانون الخدمة المدنية.

### و. المحاكم والعرائض القضائية غير المالية (`court-petitions`)
- **طلب حجة حصر وراثة**: استدعاء موجه لمحكمة الأحوال الشخصية / المواد الشخصية.
- **طلب حجة ولادة متأخرة**: للأطفال غير المسجلين ضمن المدة القانونية أمام محكمة الأحوال الشخصية.
- **طلب قسام شرعي / نظامي**: لتوزيع التركة وتحديد السهام الشرعية.
- **المصادر**: قانون المرافعات المدنية رقم 83 لسنة 1969، وقانون رعاية القاصرين رقم 78 لسنة 1980، وموقع مجلس القضاء الأعلى (`https://sjc.iq`).

## ٤ — قائمة المرفوضات (لقرارات المالك أو عدم وجود مصدر رسمي)

| البيان / المعاملة | سبب الرفض والمنع الصارم |
|---|---|
| **العقود بكافة أنواعها (بيع، شراء، إيجار، مقاولة)** | حُذفت بقرار المالك الصريح يوم ٢٩ أيلول ٢٠٢٦ — البرنامج ليس نظاماً مالياً أو تعاقدياً |
| **الكمبيالات والوصولات وسندات الأمانة** | معاملات مالية محظورة بقرار المالك التأسيسي |
| **الوكالات الشرعية والعامة والخاصة** | اختصاص حصري لدوائر كاتب العدل؛ ونماذجها خارج نطاق أوراق الاستنساخ |
| **كتب وملازم المدارس** | رُفضت صراحة بقرار المالك في المبادئ التأسيسية |
| **أي معاملة تتضمن ختماً رسمياً أو باركوداً مزوراً أو شعار جمهورية العراق مصمماً مسبقاً** | انتهاك للمبدأ ٤ ومبدأ الشرعية؛ الورقة تطبع بيضاء ليوقعها ويختمها الموظف الحي في الدائرة |
| **أي معاملة تتضمن اسم مدرسة أو مديرية أو محكمة بعينها** | انتهاك للمبدأ ١؛ النماذج نوعية، والجهة المخاطبة حقل يملأه الموظف |
| **المعاملات التي لا يمكن إثبات صيغتها أو سندها الإداري العراقي** | «الكتاب الرسمي لا يحتمل التخمين» (المبدأ ٥) |
