# حزمة المحاكم والعرائض الشرعية (`court-petitions`)

حزمة نماذج العرائض والاستدعاءات غير المالية الموجهة لمحاكم الأحوال الشخصية في العراق.

## المحتويات
- **CRT-01**: طلب حجة حصر وراثة شرعية
- **CRT-02**: طلب حجة ولادة متأخرة
- **CRT-03**: طلب قسام شرعي
- **٣ كليشات رسمية للعرائض الشرعية**
