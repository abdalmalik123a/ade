# modnet-portrait-q8.onnx

نموذج فصل الشخص عن خلفيّته في «الصور الشخصية» — يعمل على الجهاز وحده، بلا شبكة.

| | |
|---|---|
| الأصل | MODNet: Trimap-Free Portrait Matting in Real Time — https://github.com/ZHKKe/MODNet |
| الملف | `onnx/model_quantized.onnx` من https://huggingface.co/Xenova/modnet (نُزِّل ٢٩ أيلول ٢٠٢٦ بإذن المالك) |
| الرخصة | Apache-2.0 |
| الحجم | 6,632,188 بايت |
| SHA-256 | `92e49898c3e05a6d7a944fc67a8cb87c4aad754ffb6ebd949528c7d1105fee3a` |
| المدخل | `input` — صورة RGB بمقاس ضلعه الأقصر ٥١٢ وكلا ضلعيه من مضاعفات ٣٢، وقيمها (x/255 − 0.5)/0.5 |
| المخرج | `output` — قناعٌ بين ٠ و١ بمقاس المدخل |

اختير المكمَّم (٨ بتّات) على الكامل (٢٥٫٩ م.ب): الفرق بينهما على صورة اختبار متوسّطه ٠٫١٩ من ٢٥٥
و٢٥ بكسلًا وحدها تختلف بأكثر من ٣٢ — والكامل أسرع (٠٫٢٨ ث مقابل ~٠٫٤٥) لكنّه أربعة أضعاف الحجم.
