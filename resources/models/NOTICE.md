# birefnet-lite-matting-q8.onnx

نموذج فصل الأشياء والمنتجات عن خلفيّتها في التصاميم (DESIGNS.md ٢٫٣) — بالمحرّك نفسه، على الجهاز وحده، بلا شبكة. والأشخاص
في «الصور الشخصية» يبقون لـMODNet: الدقّة فيهم واحدة، وMODNet أسرع سبع مرّات.

| | |
|---|---|
| الأصل | BiRefNet: Bilateral Reference for High-Resolution Dichotomous Image Segmentation — https://github.com/ZhengPeng7/BiRefNet |
| الأوزان | `model.safetensors` من https://huggingface.co/ZhengPeng7/BiRefNet_lite-matting (نُزِّل ١٠ تشرين الأول ٢٠٢٦ بإذن المالك)، SHA-256 `ce8bcfc045e336322c0424a5863dcfb7e9ce8fed0a5fd4d1b2b20adf12d97243` |
| التدريب | مطابقةٌ عامّة (matting): صورٌ شخصية بشعرها وبشرٌ وحيوانات وأشياء (P3M-10k وAM-2k وAIM-500 وDistinctions-646 وHIM2K وPPM-100) |
| الرخصة | MIT |
| التحويل | `tools/models/convert-birefnet.py`: الالتفاف المشوَّه بمثيله المعياريّ (`deform_py.py`)، وONNX بمقاس ٥١٢، وتهيئة ONNX Runtime، و٨ بتّات |
| الحجم | 55,759,811 بايت |
| SHA-256 | `8235758d93b7577331891330521245c51114305af3f3ef2d1f5b64424568cc0e` |
| المدخل | `input` — صورة RGB بمقاس ٥١٢ × ٥١٢ (تُمطّ)، وقيمها (x/255 − متوسّط ImageNet) / انحرافه |
| المخرج | `output` — قناعٌ بين ٠ و١ بمقاس ٥١٢ × ٥١٢ |

القياس على هذا الجهاز (i5-1035G1، ٧٫٧ غيغا) بمجموعةٍ أقنعتها معروفة: الشخص ٩٩٫٤٪ (MODNet ٩٩٫٥٪)، والكوب ٩٠٪ (MODNet ٠٪)،
والتفّاحة ٩٩٫٦٪ (MODNet ٧٧٪)؛ و٢٫٦ ثانية للصورة. والتحويل يطابق الأصل بفرقٍ ٠٫٠٠٠٠٥، والثماني بتّات تُبقي الدقّة كما هي
(١٨٣ ← ٥٣ م.ب). وبمقاس ٧٦٨ أدقّ حافّةً قليلًا لكنّه ٥ ثوانٍ و١٠٦ م.ب — فاختير ٥١٢.

# face_detection_yunet_2023mar.onnx

نموذج الوجه في «الصور الشخصية» (إصلاح البند ٣٩): يجد الوجه وعينيه وأنفه وطرفي فمه، فيُعرف منه **الذقن الحقيقيّ** للياقة
تلقائيًّا و«رمّم» ودليل الرأس في القالب — بالمحرّك نفسه، على الجهاز وحده، بلا شبكة. والصورة لا تغادر العملية الرئيسة.

| | |
|---|---|
| الأصل | YuNet من OpenCV Zoo — https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet |
| الملف | `face_detection_yunet_2023mar.onnx` من https://huggingface.co/opencv/face_detection_yunet (نُزِّل ١٣ تشرين الأول ٢٠٢٦ بإذن المالك)، وبصمته نفسها في مستودع OpenCV Zoo على GitHub |
| الرخصة | MIT — Copyright (c) 2020 Shiqi Yu (سطر الحقوق كما تشترطه الرخصة) |
| الحجم | 232,589 بايت |
| SHA-256 | `8f2383e4dd3cfbb4553ea8718107fc0423210dc964f9f4280604804ed2552fa4` |
| المدخل | `input` — صورة BGR بمقاس ٦٤٠ × ٦٤٠ (تُصغَّر بنسبتها إلى الزاوية العليا والباقي أسود)، وقيمها ٠..٢٥٥ كما هي |
| المخرج | `cls_*` و`obj_*` و`bbox_*` و`kps_*` لكلّ خطوة (٨ و١٦ و٣٢) — تُفكّ كما في OpenCV (`FaceDetectorYN`) في `src/shared/portraitFace.ts` |

القياس على ثماني صورٍ حقيقية (بلحىً ونظّارات وياقاتٍ مرتفعة — لا تُودَع): وُجد الوجه فيها كلّها بثقة ٠٫٩٣–٠٫٩٥ وفي ٢٠–١٣٠
ملّي ثانية. والذقن من حافّة الإضاءة تحت الفم أخطأ بـ٠٫٠٣ من المسافة بين العينين والفم وسطًا (أسوأه ٠٫١١)، وتقدير القناع
كان يضعه على الشفة (٠٫٢٣–٠٫٦٧ تحت الفم بدل ~٠٫٨٥).
